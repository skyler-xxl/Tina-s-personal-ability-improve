# 02｜HTML 阅读笔记

用于把一本书蒸馏成结构化、可阅读、可长期保存的单文件 HTML 阅读笔记。

## 标准结构

**八大原有模块 + 全书各章节精读**

1. Hero / 书籍视觉封面
2. 书籍档案
3. 一句话总览
4. 全书章节脉络图
5. 章节摘要
6. 章节精读
7. 金句
8. 对工作与决策的行动启发
9. 适合谁读
10. 页脚

### 章节摘要 vs 章节精读

- **章节摘要**：快速浏览，解决“这本书每章讲了什么？”
- **章节精读**：深度吸收，解决“这一章有什么关键表达，以及我能怎么用？”

章节精读每章固定包含：

- 凝练摘要
- 重点例句 / 关键原文
- 对工作和生活的启发

## 目录

- `SKILL.md`：完整生产流程与质量红线
- `references/content-spec.md`：内容组织规范
- `assets/template.html`：视觉与页面母版
- `scripts/optimize_images.py`：图片压缩
- `scripts/embed_images.py`：图片 Base64 内嵌，生成真正单文件 HTML

## 工作流

原始书籍 → 完整通读 → 知识蒸馏 → 章节摘要 + 章节精读 → HTML 模板 → 图片内嵌 → 响应式质检 → 单文件交付
