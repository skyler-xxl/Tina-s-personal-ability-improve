# 02｜读书蒸馏

用于把一本书蒸馏成结构化、可阅读、可长期保存的单文件 HTML。

> **调用关键词：读书蒸馏**
>
> 后续在对话中直接说“读书蒸馏”，即可按本 Skill 的标准流程处理指定书籍。

## 当前版本

**v1.1**

本版本新增：

- 任务路由：先判断用户核心目标，再决定是否调用读书蒸馏
- 不适用边界：数据、流程、实时信息、决策、短文本等不强行套用读书蒸馏
- 资料不足与 OCR 风险处理规则
- 论文、长文、演讲、课程、报告等兼容模式

## 标准结构

**八大原有模块 + 全书各章节精读**

1. Hero / 书籍视觉封面
2. 书籍档案
3. 一句话总览
4. 全书章节脉络图
5. 章节摘要
6. 章节精读
7. 金句
8. 对工作与决策的行动启发
9. 适合谁读
10. 页脚

### 章节摘要 vs 章节精读

- **章节摘要**：快速浏览，解决“这本书每章讲了什么？”
- **章节精读**：深度吸收，解决“这一章有什么关键表达，以及我能怎么用？”

章节精读每章固定包含：

- 凝练摘要
- 重点例句 / 关键原文
- 对工作和生活的启发

## 任务边界

### 适合

- 书籍
- 长篇知识材料
- 以理解、吸收和长期复用为主要目的的内容

### 不直接套用标准结构

- Excel / CSV / 数据库 / 统计数据 → 数据分析
- SOP / 操作手册 / API 文档 / 技术规范 → 流程或技术文档解析
- 新闻 / 实时行情 / 最新政策 / 最新价格 → 实时检索或研究
- 比较 / 评估 / 预测 / 风险判断 / 方案选择 → 研究或决策分析
- 短通知 / 邮件 / 聊天记录 → 直接处理

论文、长篇文章、演讲稿、课程、报告可以使用“蒸馏”思想，但根据材料类型切换为对应模式，不为了套模板而虚构章节。

## 目录

- `SKILL.md`：完整生产流程、任务路由与质量红线
- `references/content-spec.md`：内容组织规范
- `assets/template.html`：视觉与页面母版
- `scripts/optimize_images.py`：图片压缩
- `scripts/embed_images.py`：图片 Base64 内嵌，生成真正单文件 HTML

## 工作流

任务判断 → 原始书籍/材料 → 完整阅读 → 知识蒸馏 → 章节摘要 + 章节精读 → HTML 模板 → 图片内嵌 → 响应式质检 → 单文件交付
