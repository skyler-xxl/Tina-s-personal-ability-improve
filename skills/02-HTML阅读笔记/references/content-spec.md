# 内容组织规范（content-spec）

读书笔记页面采用“八大原有模块 + 章节精读”的固定内容结构。全部事实性内容以所读书籍原文为主要事实来源；无法确认的信息标注“待补充”或“待核对原文”。

## 0. 页面总结构

导航锚点 → Hero → 书籍档案 → 一句话总览 → 全书章节脉络图 → 章节摘要 → 章节精读 → 金句 → 行动启发 → 适合谁读 → 页脚。

固定区块 id：bookinfo、overview、map、chapters、chapter-deep、quotes、actions、audience。

## 1. Hero（碧海蓝天大图压标题）

背景使用碧海蓝天类大景图，标题压图，底部渐隐融入纸面背景。包含眉标、书名、副题、作者/出版·年份/领域三枚元信息、一段 2–3 句总览短句。手机端必须完整显示标题与短句，不裁切。

## 2. 书籍档案

字段：书名、作者、出版、领域、定位（如有）、核心命题。缺失则标注“待补充”，不编造。真实封面置于档案卡。

## 3. 一句话总览

把全书压成 2–4 句的 30 秒版。优先使用原书核心对立结构和概念，允许适度合并原书表述，但不得新增原书没有的观点。

## 4. 全书章节脉络图

用 3 步主线表达全书主轴；主体严格按照原书实际章节结构组织；每章节点包含章名、章旨和与原书一致的节名。

## 5. 章节摘要——快速浏览

目标：回答“这本书每章讲了什么？”

每章一张卡片：章序号 + 章标题 + 一句话章旨；每节一行：节名 + 1–2 句摘要。摘要采用“概念 + 书中要点”，信息密度高，可脱离原书独立快速阅读。必须覆盖全书章节，节名与原书目录一致。

## 6. 章节精读——深度吸收

目标：回答“这一章有什么关键表达，以及我能怎么用？”

这是与“章节摘要”并列的独立模块，不得合并。每章固定三部分：

### 6.1 凝练摘要
用一段更高密度的文字解释本章核心逻辑、关键概念或作者主要论证。可综合本章多个小节，但必须忠于原文。

### 6.2 重点例句 / 关键原文
选择 1 条最能代表本章的短句、例句或关键原文，并标注章节/小节出处。无法逐字核验时不得伪造引号，改为“关键表达（待核对原文）”。

### 6.3 对工作和生活的启发
说明本章知识在工作、生活、选择或决策中如何落地，必须绑定本章概念，避免泛泛而谈。

## 7. 金句（3–6 条）

逐字摘自原书，含标点并标注出处。优先覆盖不同章节。长段落不作为金句大段复制。

## 8. 对工作与决策的行动启发（5–7 条）

每条包含编号、祈使句标题、2–3 句可执行建议。建议必须绑定书中具体概念，并落在工作/决策场景。

## 9. 适合谁读（4–6 条）

读者画像具体可对号入座，并给一句说明；不要用泛化营销语言。

## 写作与事实标准

- 所有数字、年份、概念、节名必须能在原书中找到；否则标注“待补充”。
- 金句逐字引用；章节精读的“关键原文”也必须可核验。
- 摘要允许转述，但不得歪曲原意。
- 页面语气安静、准确、有书卷气，不使用营销腔。
