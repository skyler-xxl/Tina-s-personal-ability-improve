# Tina-s-personal-ability-improve

个人能力提升与知识管理仓库。

## 底层架构

```
Tina-s-personal-ability-improve/
├── README.md
├── skills/
│   ├── 01-知识萃取/
│   └── 02-HTML阅读笔记/
├── templates/
│   └── reading-note/
├── books/
│   └── README.md
├── knowledge/
│   └── README.md
└── index/
    └── README.md
```

## 分层职责

- **skills**：定义“怎么做”，沉淀可复用的方法、流程与规范。
- **templates**：定义“长什么样”，提供稳定的 HTML 阅读笔记模板。
- **books**：记录具体书籍/资料的学习过程与成品。
- **knowledge**：沉淀跨来源、可长期复用的结构化知识。
- **index**：建立整个知识库的统一入口和检索索引。

## 核心工作流

```
原始资料
  ↓
知识萃取 Skill
  ↓
结构化知识
  ↓
HTML 阅读笔记 Skill + Template
  ↓
Books / 成品
  ↓
Knowledge / 长期沉淀
  ↓
Index / 全局索引
```

后续可以在这个骨架上继续加入更多 Skills、HTML 模板、具体书籍、知识主题和自动化索引。

> 原则：Skill 负责“怎么做”，Template 负责“长什么样”，Books 负责“学了什么”，Knowledge 负责“沉淀什么”，Index 负责“在哪里找到”。
