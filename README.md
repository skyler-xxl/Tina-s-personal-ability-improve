# Tina-s-personal-ability-improve

Tina's personal ability improvement knowledge base.

## Repository structure

- `skills/` — reusable knowledge-processing skills
  - `01-知识萃取/` — knowledge extraction and distillation
  - `02-HTML阅读笔记/` — **读书蒸馏**：book-to-HTML reading distillation
- `templates/reading-note/` — reusable reading-note templates
- `books/` — book source materials and reading records
- `knowledge/` — distilled, structured knowledge assets
- `index/` — knowledge-base indexes and navigation

## Workflow

原始资料 → 知识萃取 → **读书蒸馏** → 结构化知识 → 索引

### 读书蒸馏

后续提到“读书蒸馏”，默认调用 `skills/02-HTML阅读笔记/SKILL.md`，按固定的“八大原有模块 + 全书各章节精读”结构生成单文件 HTML。
